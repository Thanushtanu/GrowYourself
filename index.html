Practice evidence

Long-running portfolio project

Build an e-commerce order data platform

You will create synthetic customers, products, orders, payments and delivery events. This gives you a coherent project to explain in interviews without exposing confidential employer data.

Final architecture (you will build it gradually)

CSV / mock API → Python ingestion → raw files → validation and transformation → PostgreSQL warehouse → analytics SQL. Later: Airflow scheduling, AWS S3, PySpark, Docker, tests and CI.

Start with local CSV files and SQLite/PostgreSQL. Do not pay for cloud services until you understand the local pipeline. Use synthetic data only.
